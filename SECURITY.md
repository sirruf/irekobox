# Security

Irekobox runs containers, serves the Docker API on a local socket and can
install a privileged helper, so security reports matter.

## Reporting a vulnerability

Please don’t open a public issue. Report it privately through
[GitHub’s vulnerability reporting](https://github.com/sirruf/irekobox/security/advisories/new)
with the steps to reproduce it and the versions involved.

You’ll get an answer within a week. Once a fix is released, the advisory is
published with credit to you, unless you’d rather stay anonymous.

## Supported versions

Fixes go into the latest release. Irekobox updates itself, so please check the
problem on the latest version first.
